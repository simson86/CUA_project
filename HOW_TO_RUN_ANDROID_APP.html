Android_run 앱 실행 가이드

폰 단독 온디바이스 Computer Use — 케이블·PC 없이 폰 안에서 Gemini가 화면을 보고 스스로 조작

이 앱이 하는 일
앱에 목표(예: 설정 앱을 열어)를 입력하면, 폰이 화면 캡처 → Gemini에 판단 요청 → 받은 UI 액션(탭/입력/스크롤)을 접근성으로 실행하는 루프를 완료까지 반복합니다. PC도, USB 케이블도 필요 없습니다(디버깅용으로만 선택).

0. 준비물

  • Android Studio (최신 안정판 권장)
  • 안드로이드 실기기 — Android 11(API 30) 이상. 접근성 화면캡처가 API 30+에서만 동작. (에뮬레이터도 되지만 실기기 권장)
  • 본인 Gemini API 키 — aistudio.google.com/apikey 에서 발급. 각자 자기 키를 씁니다.
  • 설치할 때만 USB 케이블 1회(또는 무선 디버깅). 이후엔 폰 단독.

1. 코드 받기

1

저장소 클론

git clone https://github.com/simson86/CUA_project.git

안드로이드 앱은 android/ 폴더에 있습니다. Android Studio에서 이 android/ 폴더를 프로젝트로 엽니다(루트가 아니라).

2. API 키 넣기 중요·비밀

2

android/local.properties 에 키 한 줄 추가

android/local.properties 파일을 열어(없으면 Android Studio가 Gradle sync 때 자동 생성) 아래 한 줄을 추가:

GEMINI_API_KEY=여기에_본인_키

빌드 시 이 값이 BuildConfig.GEMINI_API_KEY로 앱에 주입됩니다(android/app/build.gradle.kts가 읽음).

🔒 절대 커밋 금지. local.properties는 .gitignore에 걸려 있습니다. 키를 소스코드나 스크린샷·채팅에 붙여넣지 마세요. 팀원끼리 키를 공유하지 말고 각자 발급해서 씁니다.

3. 빌드 & 설치

3

Android Studio에서 실행

  • Gradle sync가 끝날 때까지 대기(처음엔 의존성 다운로드로 몇 분 걸릴 수 있음).
  • 폰을 USB로 연결 + 개발자 옵션 > USB 디버깅 켜기.
  • 상단 툴바에서 기기 선택 후 ▶ Run → 폰에 앱 설치.

참고 설정: applicationId = com.cua.a11, minSdk 30, targetSdk 36, compileSdk 37.

4. 폰에서 권한 3개 켜기 필수

4

앱이 화면을 읽고 조작하고, 진행 상황을 알리려면 아래 권한이 필요합니다.

권한어디서용도
접근성설정 > 접근성 > Android_run > 켜기화면 캡처 + 탭/입력 실행 (핵심)
알림앱 첫 실행 시 팝업 → 허용실행 완료/오류 알림
다른 앱 위에 표시실행 누르면 설정으로 안내 → 켜기실행 중 진행 오버레이 창
⚠️ 앱을 재설치하면 접근성 토글이 꺼질 수 있습니다. 빌드/재설치 후엔 설정 > 접근성에서 다시 켜세요.

5. 실행

5
  • 앱을 열고 입력창에 목표를 한글/영어로 입력 — 예: 설정 앱을 열어
  • 실행 버튼 → 폰이 알아서 화면을 보며 단계별로 조작.
  • 조작 대상 앱 위에 오버레이 창이 떠 지금 턴을 실시간 표시.
  • 끝나면 상태바 알림으로 결과 표시(✅ 완료 / ⚠ 최대 턴 / ❌ 오류). 알림 탭 → 앱 복귀.
  • 지난 로그 보기: 실행 기록은 폰에 저장돼 언제든 다시 조회(‘로그 지우기’로 비움).

첫 목표는 설정 앱을 열어 처럼 안전하고 짧은 걸로 테스트해 보세요.

🚫 안전 경고 — 지금은 자동승인 상태
현재 위험 액션도 사람 확인 없이 자동 진행됩니다. 결제·구매·송금·삭제·전송 같은 되돌릴 수 없는 작업은 시키지 마세요. “장바구니 담기까지”, “검색까지”처럼 되돌릴 수 있는 범위만 테스트하세요. (실제 결제 마지막의 지문/PIN 화면은 보안상 접근성으로 조작 불가라 거기서 멈추긴 합니다.)

6. (선택) PC에서 원격 트리거 — 디버깅용

폰 단독으로 충분하지만, PC에서 목표를 쏘고 싶으면 폰과 같은 Wi-Fi에서:

# 저장소 루트에서 (Python은 반드시 py 런처)
py tools/send.py "설정 앱을 열어"      # 폰이 목표를 자율 실행
py tools/send.py --shot               # 현재 폰 화면 캡처 → after.png

폰 IP는 --ip 192.168.x.x 로 지정(설정 > Wi-Fi 상세에서 확인). 공유기 “AP 격리”가 켜져 있으면 소켓이 안 붙습니다.

문제 해결

증상원인 / 해결
빌드 에러 unresolved reference: BuildConfigbuildConfig = true 확인 + Gradle sync 다시. (이미 설정돼 있음)
실행하면 “접근성 서비스가 꺼져 있습니다”설정 > 접근성에서 Android_run 켜기(재설치 후 꺼짐)
“다른 앱 위에 표시 권한 필요” 반복안내된 설정 화면에서 권한 ON 후 다시 실행
실행은 되는데 알림이 안 옴앱 알림 권한 허용 여부 확인(설정 > 앱 > Android_run > 알림)
HTTP 400/403 또는 즉시 오류local.properties의 GEMINI_API_KEY 오타/누락, 또는 키 권한 문제
탭이 좌상단만 눌림드물게 좌표 환산 문제 — 최신 코드인지 확인(정상 빌드면 발생 안 함)
